The Hypothesis

Why this experiment?

🎯

The problem

Extra's core promise is giving you back hours every week — but users never see it. The value is invisible. If you don't feel the benefit, you don't build the habit.

💡

The experiment

Send a personalized weekly push notification on Sunday evenings showing exactly how many minutes Extra saved each user — broken down by category, not as a generic re-engagement nudge.

📊

The hypothesis

Users who receive a concrete, personalized time-saved number will have meaningfully higher 7-day retention than those who receive no notification or a generic re-engagement message.

Primary metric: 7-day retention Secondary: DAU/WAU ratio Duration: 14 days Split: 50/50 control vs variant

A/B Test Design

Three variants, one winner.

Control group

No notification
(No weekly notification sent)

Users receive only in-app activity — no push notification about weekly usage or savings.
Purpose: Baseline to measure organic 7-day retention and DAU/WAU without any weekly nudge. If variants don't beat this, the experiment fails.

What we're measuring

Against this baseline, any uplift in Variant A or B is attributable to the notification itself — not organic app behavior.

  • → 7-day retention rate — did they open the app again within a week?
  • → DAU/WAU ratio — are they coming back more frequently?
  • → Notification CTR — did they tap through to the app?
  • → Feature depth — did they engage with more features after seeing savings?

Variant A — Time Saved

Personalized value

Why this variant should win

Time is the most emotionally resonant resource. Showing someone they got 47 minutes back triggers a stronger response than "you have new summaries." It makes the value proposition felt, not just understood.

The breakdown (threads, noise, replies) adds credibility — it doesn't feel like a made-up number. Each line is auditable.

Variant B — Streak

Habit formation

This week: 47 minutes saved. Last week: 39 minutes. You're getting more out of Extra every week.

Hypothesis: Adding a streak mechanic (like Duolingo) activates loss aversion — users don't want to break the streak. Tests whether habit-formation framing outperforms pure value framing from Variant A.

A/Bvs Variant A

Streak vs. value: the real test

Variant B isn't just testing a different message — it's testing a different psychological lever. Variant A says "look what Extra did for you." Variant B says "look what you and Extra have built together."

If B beats A, Extra should invest in a streak/habit system. If A beats B, double down on personalized value reporting. Either answer is useful.

Full Experiment Spec

How to run this in 5 days.

📐 Setup (Days 1–2)

  • Define the instrumentation: confirm that thread summarizations, filtered emails, and drafted replies are already logged per user per week
  • Build the computation layer: simple script — sum per-user weekly actions × estimated time saved per action (configurable constants)
  • Create 3 notification templates in your push notification tool (e.g. OneSignal, Braze, Firebase), parameterized by user stats
  • Set up 50/50 random split at the user level — lock assignment at experiment start, don't re-randomize

🧪 Run (Days 3–16)

  • Send cadence: Sunday evening, 7–8pm local time — highest open rates for consumer apps
  • Run duration: 2 full weekly cycles (14 days) — enough for 2 notification touches per user
  • Track daily: retention rate by cohort, CTR on notification, feature engagement post-open
  • Do not adjust notification copy mid-run — lock variants before launch
  • Monitor opt-out rate — if Variant X drives significantly more notification opt-outs, that's a negative signal even if retention looks good

📊 Measure (Day 17)

  • Primary: 7-day retention rate per variant — did users open the app within 7 days of receiving the notification?
  • Secondary: DAU/WAU ratio — are notified users building a stronger daily habit?
  • Secondary: CTR on the notification itself — are users tapping through?
  • Guardrail: notification opt-out rate must not be materially higher than control's baseline churn
  • Significance threshold: p < 0.05 with minimum detectable effect of +5pp on retention

⚙️ Technical notes

  • Time saved calculation: configurable constants (e.g. 2 min/thread, 0.2 min/filtered email, 1.5 min/draft) — tune based on user research, not assumptions
  • Edge case — new users: users with < 5 actions in the week get a different message: "Extra is just getting started for you — here's what it caught this week"
  • Edge case — power users: cap the displayed number at 120min — anything above strains credibility
  • Personalization: use first name in notification if available — small uplift on open rates
  • Future iteration: if A or B wins, test sending on Thursday instead of Sunday to see if mid-week reinforcement changes habit formation
Decision framework — what to do with results
▶
Day 17: Results are in
Compare 7-day retention across Control, Variant A, Variant B
✓
Variant A or B beats control by ≥ 5pp (p < 0.05)
Experiment succeeds → roll out winning variant to 100% of users → build permanent "Weekly Recap" feature into product roadmap
✓
Both A and B beat control, but A > B
Value framing wins over habit framing → invest in personalized time-saved reporting → de-prioritize streak mechanic
~
Both A and B beat control, B > A
Habit formation wins → build a streak system → test weekly cadence vs. daily check-in notification in follow-up experiment
~
Small lift (< 5pp) — inconclusive
Re-run with larger user sample or longer duration → test notification timing (Thursday vs Sunday) → consider whether the message copy needs a stronger hook
✕
No lift, or variant drives higher opt-out rate
Weekly push is not the right channel → test in-app card instead (shown on Monday morning open) → the insight is still valid, the channel may not be
